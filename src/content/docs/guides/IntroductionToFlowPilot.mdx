## Running FlowPilot

Flow Pilot can run on any Actor that can have a <LinkRef c="UFlowPilotComponent" /> added to it. 

<Steps>

1. Add a new Actor to the Level and add a <LinkRef c="UFlowPilotComponent" /> to it.
    <Image src={add_flowpilot_comp} alt="Add FlowPilotComponent Component to Actor" />

2. In the Details panel, find `Flow Pilot Asset` and add the newly created `FP_Tutorial` in.
    <Image src={link_fp_asset} alt="Link FlowPilot Asset" />

3. At this point, we should tick `Auto Start on Begin Play` so that Flow Pilot starts automatically. 

4. Execution Mode handles how FlowPilot runs. For now, we can leave it as `Run Once`. 

</Steps>

Great stuff! Flow Pilot asset is created and linked to a Flow Pilot Component! 
Lets open `FP_Tutorial` to start editing.

## Change Spawn Location

import reference_spawn from '../../../assets/reference_spawn.png';
import runtime_tags from '../../../assets/runtime_tags.png';

Right now, the AI we're spawning is using the Actor where <LinkRef c="UFlowPilotComponent" /> was added, as the source location.
This is done with the Property: `LocationType` and Property `Spawn Location Reference`. This property is a custom type called <LinkRef c="FFlowActorReference" />.

LocationType can be defined as World, where you can set a custom world location. Alternatively, you can set it to `Reference`. Choosing `Reference` allows you to pick `Self` which is the current actor, `In Level` which allows you to pick any actor in the level, or `Runtime` which is a reference to an actor in the level via GameplayTag.
