Fixing the Demo Level ​

The FlowPilot_DemoLevel map does not play out of the box on purpose: it needs your own character. Fixing it takes a few minutes and shows how a real flow spawns and possesses the player.

  1. Open FlowPilot_DemoLevel.

  2. In the Outliner, select FlowPilotActor, then its FlowPilot Component, and find Flow Pilot Asset.

  3. Open FP_DemoLevel_Main and select the Spawn Player Task.

  4. In Task Details, set Spawn Class to your own character Blueprint.

    Tags To Add Actor

    The spawned character gets the Player.Character tag so later Tasks can find it quickly. If you don't have that tag, create any unique tag and use it in the next step too.

  5. Select Possess Player and check that Pawns To Possess uses the Runtime scope with the same tag as step 4.

  6. Save the asset. In your GameMode, set Default Pawn Class to None: the flow spawns the player instead.

  7. Press Play.
